# AfterImage2D
A general-purpose Node that will generate an optimized Afterimage effect. 


✨Features:

- ✅Easily customizable!  
- ✅Frame Continuity toggle (Remembers the properties of the sprite frame including it’s texture, transform and more) 
- ✅Built in Monochrome Shader option to create single-colored copies of the sprite frame
- ✅Frame velocity options (If the effect should drift off in a direction)
- ✅Uses Object Pooling to avoid creation & deletion of image objects during runtime.
- ✅Works in the editor!
